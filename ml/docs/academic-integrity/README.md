# Academic integrity boundary

The supplied Assignment 1 and Assignment 2 specifications prohibit generative AI from generating assessment materials/content. This repository may contain AI-assisted engineering scaffolding and internal technical support, but user-written submission material must comply with the unit rules.

The supplied Assignment 3 specification permits AI for learning, idea generation, and debugging support subject to acknowledgement and the student's own understanding. Consult the current official specification if requirements change.

This note is not a submission-ready AI acknowledgement and should not be copied into an assessment without the student's review and compliance check.
