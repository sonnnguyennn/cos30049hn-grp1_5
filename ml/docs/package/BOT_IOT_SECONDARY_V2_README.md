
Only fit classifiers/clustering on Kaggle, including smoke. Review before training.
TEST access requires explicit `allow_test=True` for authorized mechanical verification;
this flag is an accidental-access seal, not encryption or permission for performance evaluation.

Numeric arrays are unscaled float64; categorical uint16 arrays index TRAIN vocabularies
plus one typed UNKNOWN slot per field.36 encoded columns are computed lazily in chunks.
Labels are original uint8 values. Metadata records canonical source index,1-based row,
pkSeqID, original exact-X group SHA256 and full group size. Membership JSONLs preserve
the prior exact bytes/digests. groups.sqlite stores original exact tuples/counts/partition;
valid unknown source strings remain recoverable there, not learned into vocabulary.

preprocessing.json stores TRAIN-only moments/vocabulary/order and identity. manifest.json
binds all payload hashes, v2 policy/protocol/decision, source commit/dirty flag, evidence,
actual memberships and preprocessor hashes. Package identity is manifest SHA256.

Full standalone verification, writing receipt **outside** the package:

```text
python -I /path/to/package/verify_package.py /path/to/package --expected-manifest SHA256 --output /fresh/external/verification.json
```

Verifier checks every payload, schema, counts, source lineage union, memberships, exact-X
group/label reconciliation,36-column schema, generic UNKNOWN and independent TRAIN moments
and vocabulary. It uses temporary disk storage outside the package; no models or TEST
performance metrics are computed. Verify a copied package in a NumPy-only environment.

Reporting: row weights1 primary; group sensitivity weights1/n_g per original exact-X group
within partition, including mixed-label groups. Report integer and weighted confusion
tables distinctly, class supports/recalls, FPR and macro-F1; accuracy supplementary.
Select model/threshold using VALIDATION only. Benign support96/95 and group concentration
limit precision; disclose group-aware uncertainty. No cross-dataset/deployment claim.
